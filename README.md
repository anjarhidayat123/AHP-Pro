Agro AHP Pro
Agribusiness Decision Support System using AHP

Agro AHP Pro adalah aplikasi Decision Support System (DSS) berbasis Analytical Hierarchy Process (AHP) yang dirancang untuk membantu pengambilan keputusan strategis di bidang agribisnis secara objektif dan terukur.

Aplikasi ini memungkinkan pengguna melakukan pembobotan kriteria, perbandingan alternatif, dan perhitungan prioritas keputusan secara sistematis.

🎯 Tujuan Aplikasi

Membantu pengambilan keputusan agribisnis berbasis metode ilmiah

Mengurangi subjektivitas dalam pemilihan alternatif

Menyediakan perhitungan prioritas yang konsisten dan transparan

Mendukung perencanaan dan evaluasi usaha agribisnis

🧠 Metode yang Digunakan

Analytical Hierarchy Process (AHP) dengan tahapan:

Penentuan tujuan

Penetapan kriteria dan sub-kriteria

Penentuan alternatif

Perbandingan berpasangan (pairwise comparison)

Perhitungan bobot prioritas

Uji konsistensi (CI & CR)

Perangkingan alternatif

🚀 Fitur Utama

📋 Manajemen Kriteria & Alternatif

⚖️ Pairwise Comparison Matrix

📐 Perhitungan Bobot Prioritas

✅ Uji Konsistensi (CR ≤ 0.1)

🏆 Hasil Ranking Alternatif

📊 Visualisasi Hasil Keputusan

💾 Penyimpanan & Riwayat Analisis

🔄 Alur Sistem

Pengguna menentukan tujuan keputusan

Menambahkan kriteria dan alternatif

Melakukan perbandingan berpasangan

Sistem menghitung bobot dan konsistensi

Hasil akhir berupa ranking alternatif terbaik

🧪 Contoh Use Case

Pemilihan komoditas agribisnis terbaik

Penentuan lokasi pabrik atau lahan pertanian

Seleksi supplier bahan baku

Penentuan teknologi pengolahan hasil pertanian

Evaluasi kelayakan strategi usaha

📊 Output Sistem

Nilai bobot setiap kriteria

Nilai prioritas setiap alternatif

Consistency Ratio (CR)

Rekomendasi alternatif terbaik

Backend: (Node.js / Python / PHP)

Database: (MySQL / PostgreSQL / SQLite)

Metode: Analytical Hierarchy Process (AHP)
